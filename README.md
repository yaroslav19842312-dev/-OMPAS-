# КОМПАС Web MVP v1.0

Рабочий стартовый MVP. Вопросы и ключи находятся в `lib/data.ts`, клиент получает только текущий вопрос через `/api/question/[id]`, расчёт выполняется на сервере.

## Запуск
Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Открыть: http://localhost:3000

## Важно
Это технический MVP рабочей методической гипотезы. Перед массовым запуском нужны пилотирование, психометрический анализ и калибровка.

Репозиторий с исходниками должен быть PRIVATE. Не публиковать `lib/data.ts`.
Production-архитектура: Next.js → Vercel → Supabase.
